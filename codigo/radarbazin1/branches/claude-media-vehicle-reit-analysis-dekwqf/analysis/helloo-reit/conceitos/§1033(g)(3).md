# §1033(g)(3)
Dispositivo do Internal Revenue Code que permite **eleger tratar um outdoor advertising
display como *real property***. Com a eleição, o painel vira "estrutura inerentemente
permanente" e seu aluguel vira **"rents from real property"**.

> [!key] Chave dos cases
> Foi o atalho usado por [[Lamar Advertising]] e [[Outfront Media]] (2014) para virarem
> [[REIT]]. Positivado depois em [[Treas. Reg. §1.856-10]] (2016).
