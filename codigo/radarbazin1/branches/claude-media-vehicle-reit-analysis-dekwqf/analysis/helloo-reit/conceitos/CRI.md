# CRI
**Certificado de Recebíveis Imobiliários** — exige **lastro em crédito imobiliário**.
Tem isenção de IR para pessoa física.

> [!failure] Descartado para a Helloo
> Recebível publicitário **não é** crédito imobiliário → CRI não se aplica.

Relacionados: [[CR genérico]] · [[FIDC]]
