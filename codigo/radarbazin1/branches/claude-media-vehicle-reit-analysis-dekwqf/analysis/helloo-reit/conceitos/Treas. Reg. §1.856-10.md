# Treas. Reg. §1.856-10
Regulamento final do IRS (**2016**) que define **real property** para fins de [[REIT]]:
*land* + *improvements to land* (estruturas inerentemente permanentes + componentes).
Inclui expressamente outdoors com eleição [[§1033(g)(3)]].
