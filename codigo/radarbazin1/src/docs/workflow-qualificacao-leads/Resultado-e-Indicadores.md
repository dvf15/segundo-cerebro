# Resultado e indicadores

> [!success] Mais agilidade, melhor qualificação e menos retrabalho para o executivo
> O ganho do fluxo não é "mais leads" — é **menos tempo do executivo gasto com
> lead que não fecha** e menos conversa repetida por falta de registro.

⬅ [[Decisao-Perfil-do-Lead|Decisão]] · 🏠 [[Fluxo-de-Qualificacao-de-Leads|Índice]]

| Indicador | Fórmula | Meta | Mês atual |

| Leads recebidos | contagem | — | |

| Taxa de triagem completa | leads com 8 respostas ÷ leads | ≥ 90% | |
| Tempo até o retorno ao lead | data decisão − data contato | ≤ 5 dias úteis | |
| Conversão triagem → viabilidade | | ≥ 60% | |
| Conversão viabilidade → proposta | | ≥ 40% | |
| Conversão proposta → contrato | | ≥ 30% | |
| Leads em `standby` com revisão agendada | | 100% | |
| Retrabalho (leads reabertos sem dado novo) | | ≤ 10% | |
