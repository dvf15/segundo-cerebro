# 📒 Vault — Copiloto de Decisão de Cláusulas (ALLOS)

Este diretório é um **vault Obsidian**. Abra a pasta `obsidian/` em **Obsidian → Open folder as vault**.

## Por onde começar
➡️ **[[00 - MOC - Projeto Cláusulas]]** — o índice (Map of Content) com toda a navegação.

Para reabrir o projeto com uma IA, use **[[Briefing - Retomar o Projeto]]** (prompt pronto).

## Estrutura
- `00 - MOC - Projeto Cláusulas.md` — índice
- `Conceitos/` — o racional completo do modelo
- `Skills/` — paleta ALLOS (pptallos) e geração de artefatos
- `Instruções/` — briefing, modelo de dados (Fase 0), parâmetros calibráveis

## Artefatos relacionados (na raiz do repositório)
- `Apresentacao_Decisao_Clausulas_ALLOS.pptx` / `.pdf` — apresentação (14 slides)
- `Modelo_Decisao_Clausulas_ALLOS.xlsx` — planilha do modelo (5 abas)
- `Decomposicao_Clausulas_ALLOS.xlsx` — tabela dos 32 tipos
