# Roadmap e Próximos Passos

> [!tip] Em resumo
> O diferencial é uma **régua clara de alçadas** — por grau, praças, portfólio e desconto — com o custo medido loja a loja.

## Roadmap por fases
| Fase | Nome | Entrega |
|---|---|---|
| **0** | Estruturar conhecimento | Migrar taxonomia, cláusulas e a régua para [[Modelo de Dados (Fase 0)|modelo de dados versionado]] |
| **1** | Motor de regras + alçadas | Codificar a régua (grau/desconto/praças/portfólio). Determinístico e auditável |
| **2** | Classificação + diff (LLM) | Cola cláusula real → identifica tipo e mede desvio/desconto |
| **3** | Cadastro + dashboard | Marcas, graus, portfólios; visão de concessões por alçada |
| **4** | Aprendizado contínuo | Log de decisões refina classificação e calibra parâmetros |

## Próximos passos imediatos
1. **Passo 1 — Validar a régua e os parâmetros** ([[Decisões a Tomar|D1–D3]]) · Diretoria + Comercial + Jurídico → confirmar 50% / 4 praças / grau A-B-Padrão.
2. **Passo 2 — Cadastrar marcas e portfólios** ([[Decisões a Tomar|D4–D5]]) · Operações central → grau de cada marca e composição de cada portfólio.
3. **Passo 3 — Governança da biblioteca** ([[Decisões a Tomar|D6–D7]]) · Jurídico + Comercial → fórmulas de custo, dono do guia e status por segmento.
4. **Passo 4 — Protótipo (Fases 0–1)** · Produto/Tech → motor de regras + console + Projeto no Claude.
