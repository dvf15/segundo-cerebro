Pontos do shopping
Filtro

Cadastre cada ponto com área e tipologia. Pontos ocupados informam a marca; pontos vagos recebem até 3 opções de mix desejado, em ordem de prioridade.

O planejamento fica salvo neste navegador. Use Backup para passar os pontos e os parâmetros a outro executivo ou aparelho, e Importar para receber — o arquivo substitui os pontos daqui. Excel (CSV) gera a lista de pontos para conferência.

Prompts de mapeamento de varejistas
Apoio, fora do fluxo principal. Estes prompts servem para complementar a base de marcas desejo com pesquisa em um modelo de IA. A triagem, os leads, o planejamento e o cruzamento funcionam sem eles.

Gera, a partir das vagas e do mix desejado cadastrados no Planejamento, um prompt pronto para você colar no seu modelo de preferência (Claude, ChatGPT, Gemini…) e sair com uma lista de marcas candidatas. Marcas que já operam no shopping ficam de fora.
