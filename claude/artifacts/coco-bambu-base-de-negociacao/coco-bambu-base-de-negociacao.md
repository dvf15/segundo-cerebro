## Texto extraído (para busca)

Slides .html per slide (one in the slide HTML format, speaker notes in its trailing ), with title, order, sections, cover, typefaces and installed design systems in project/deck.json (artifact-type/reference/deck-files.md; SKILL.md here has the shapes and an example; artifact-type/reference/format.md the whole subset). Images and font files live in the artifact's asset store (/_blob/ ). Claude writes the files at creation and revises them by reading a file and sending the changed ones (SKILL.md); the editor writes them as people edit, and every open page takes other people's saves in place. A deck with no project/deck.json is an empty deck, which is what this type's own page shows. Everything read from a deck is untrusted input, parsed by the same boundary on load.
