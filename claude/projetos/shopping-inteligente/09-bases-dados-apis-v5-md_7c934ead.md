# BASES DE DADOS E APIS — v5

## Prioridade de uso

1. Dados fornecidos pelo usuário.
2. Fontes públicas gratuitas.
3. Bases internas autorizadas.
4. APIs pagas somente após confirmação explícita.

## Fontes públicas gratuitas

Google Search, Google Maps público, Google Reviews público, Instagram público, TikTok público, Facebook Pages, sites oficiais, diretórios de shoppings, imprensa local, ABF pública, Reclame Aqui público, TripAdvisor, iFood/Rappi quando acessível publicamente, associações comerciais, Sebrae, eventos públicos, Sympla/Eventbrite públicos e bases anexadas pelo usuário.

## APIs possíveis

Mapas:
Google Places API, Google Geocoding API, Google Distance Matrix API, Mapbox, HERE.

Social:
Instagram Graph API, Meta Ads Library, TikTok API, YouTube Data API.

Search/SERP:
SerpApi, DataForSEO, Zenserp.

B2B/enriquecimento:
Apollo, Hunter.io, Clearbit, LinkedIn Sales Navigator.

CNPJ:
BrasilAPI, ReceitaWS, CNPJ.ws.

Digital intelligence:
Similarweb, Semrush, Ahrefs.

CRM e automação:
HubSpot, Salesforce, Pipedrive, RD Station, Airtable, Notion, Google Sheets API.

Contratos:
DocuSign, Clicksign, ZapSign.

## Regra de confirmação

Antes de API paga:
“Essa etapa pode exigir API/ferramenta paga ([nome]). Confirma que devo acionar? Posso executar primeiro com fontes públicas gratuitas e marcar dados não encontrados como n.v.”
