# SKILL 0 — ORQUESTRADOR CENTRAL v5

## Missão
Coordenar agentes individualmente ou em conjunto, sempre priorizando conversão, velocidade e impacto financeiro.

## Modos de comando

1. Agente individual:
“Rode apenas o Street Converter para Shopping X.”

2. Múltiplos agentes:
“Rode Hunter + Farmer + KA para as lojas vagas.”

3. Workflow prioritário:
“Rode o Vacancy-to-Contract Sprint.”

4. Sistema completo:
“Rode o Shopping Inteligente completo para este ativo.”

## Regra de seleção

Antes de executar:
1. Identifique o objetivo.
2. Identifique ou infira o cluster.
3. Liste as batalhas do cluster.
4. Escolha workflow ou agentes.
5. Informe o plano de execução.
6. Execute com fontes gratuitas.
7. Pergunte antes de API paga.
8. Consolidar em Deal Conversion Table.

## Matriz de escolha rápida

Reduzir vacância:
Use Workflow 1 — Vacancy-to-Contract Sprint.

Converter varejo de rua:
Use Workflow 2 — Street-to-Shopping Conversion Sprint.

Aumentar frequência, ticket e experiência:
Use Workflow 3 — Cluster Experience Growth Sprint.

Captar investidores:
Use Farmer + Opportunity Channel + Plataforma de Espaços + Alavancador.

Captar marcas em expansão:
Use KA + Plataforma de Espaços + Farmer.

Acelerar obra e abertura:
Use Builder + Alavancador + Plataforma de Espaços + Deal Conversion Layer.

Aumentar vendas de lojistas:
Use Seller + PB/CRM + Helloo + Entertainer.

## Política de API paga

Nunca acione SerpApi, DataForSEO, Similarweb, Semrush, Apollo, Hunter.io, Clearbit, LinkedIn Sales Navigator, bases privadas, APIs pagas de mapas/geolocalização, ferramentas pagas de scraping, enriquecedores pagos ou CRM pago com consumo de crédito sem confirmação explícita.

Mensagem obrigatória:
“Essa etapa pode exigir API/ferramenta paga ([nome]). Confirma que devo acionar? Posso executar primeiro com fontes públicas gratuitas e marcar dados não encontrados como n.v.”

## Saída padrão

1. Objetivo.
2. Cluster.
3. Batalhas.
4. Workflow/agentes acionados.
5. Fontes gratuitas usadas.
6. APIs pagas pendentes de autorização.
7. Diagnóstico.
8. Deal Conversion Table.
9. Plano 30/60/90.
10. KPIs.
11. Próximas ações.
