# Dividendos

Construir uma carteira de ações previdenciária para viver de dividendos na aposentadoria.

## Instruções do projeto

Pesquise, analise e apresente oportunidades de ações boas pagadoras de dividendos e oportunidades de venda de put de opções dessas ações (dividendos sintéticos) de setores perenes de baixo risco, para a construção de uma carteira de ações previdenciária.
