Agente 01

Hunter de Inovação

🔍

Agente Hunter — Prospecção Ativa de Inovação no Varejo

Auxilia o executivo de vendas na busca de negócios, marcas e tendências num raio de 2 a 50km do shopping

Filtros do Agente
  • Raio geográfico: 2km (mín.) a 50km (máx.) do shopping — configurável por EV
  • Categoria de varejo: moda, alimentação, serviços, entretenimento, saúde/beleza, casa/deco, esporte, pet, tech
  • Presença no shopping: ausente / presente com gap de qualidade / concorrente direto
  • Faturamento estimado: cruzamento com CNPJ + dados SERASA/Receita
  • Tempo de operação: <1 ano / 1-3 anos / 3+ anos (maturidade do negócio)
  • Presença digital: redes sociais, e-commerce, Google Reviews, seguidores
  • Ticket médio estimado: popular / mid-market / premium / luxo
  • Alinhamento ao mix planejado do shopping (plano de mix pré-carregado)
  • Tendências de busca local: Google Trends + Waze + dados do app do shopping
Bases de Dados Necessárias
✅ CNPJ / Receita Federal ✅ Google Maps API ⚠️ Dados sociais (scraping) 🔴 Plano de Mix do Shopping 🔴 Histórico de vacância ⚠️ SERASA Experian API ✅ Google Trends API
Output para o EV
  • Lista priorizada de alvos com score de fit ao shopping
  • Ficha do negócio: endereço, contato, redes sociais, faturamento estimado
  • Justificativa de fit: por que esse negócio eleva o mix?
  • Sugestão de abordagem e script de primeiro contato
  • Mapa geográfico dos alvos com rota otimizada para visitas

⇄

Match
Inteligente

🏪 Franquia estabelecida
🛍 Operação própria
🎪 Pop-up / Quiosque
🤝 Marca buscando sócio-operador
Filtros de Perfil do Investidor
  • Capital inicial disponível: faixas R$30k / R$80k / R$150k / R$300k / R$500k+
  • Capital de giro: meses de runway disponíveis (3 / 6 / 12 meses)
  • Experiência prévia: nenhuma / varejo / gestão / franquias / empreendedorismo
  • Disponibilidade de tempo: operador integral / parcial / sócio-investidor passivo
  • Expectativa de retorno: payback esperado (18 / 24 / 36 / 48 meses)
  • Tolerância a risco: conservador / moderado / arrojado
  • Categoria de interesse: alimentação / moda / serviços / etc.
  • Localização: mora perto do shopping? Raio de deslocamento
  • Score de crédito: integração SERASA para verificar capacidade financeira
Filtros de Oportunidade (Output do Match)
  • Formato: loja / quiosque / pop-up / corner store
  • Tamanho m²: compatível com capital disponível para obra
  • Marca/franquia: alinhada ao perfil de operador (exige dedicação integral? aceita sócio passivo?)
  • Royalties e taxas: compatíveis com expectativa de retorno
  • Piso / localização interna: fluxo adequado à categoria
  • Vizinhança de lojas: fit de mix (âncoras, corredores temáticos)
  • Condições comerciais: preço m² + luvas + carência (dados do sistema Bahia)
  • Score de fit: pontuação 0-100 calculada pelo agente
Agente 03

KA / Expansão de Marcas

🏢

Agente KA/Expansão — Curadoria de Marcas em Expansão

Organiza marcas e franquias que buscam novas praças e faz o match automático com o Farmer

Filtros de Cadastro da Marca
  • Praças de interesse: cidade, região, DDD — tem interesse na praça do shopping?
  • Modelo de expansão: loja própria / franquia / licenciado / corners em multimarcas
  • Perfil do parceiro buscado: operador ativo / sócio-investidor / apenas aluguel
  • Requisitos técnicos: m² mín/máx, pé-direito, vitrine (ml), energia (kVA), água/esgoto, acesso a docas
  • Vizinhança ideal: âncoras de referência, categorias complementares
  • Investimento inicial da franquia: faixas de capital exigido
  • Histórico de performance: faturamento médio das unidades existentes
  • Status de expansão: ativa buscando / em análise / pausa
Match com Plataforma Farmer
  • Cruzamento automático: perfil do investidor (Farmer) ↔ requisitos da marca (KA)
  • Alerta em tempo real quando novo investidor qualificado entra no Farmer
  • Score de compatibilidade marca ↔ investidor ↔ ponto físico disponível
  • KA humano acionado apenas para negociação de contrato e aprovação final
Bases Necessárias
🔴 CRM de marcas/franquias 🔴 Banco de pontos vagos ⚠️ ABF (Assoc. Brasileira de Franchising) ✅ Sistema Bahia (preços)
