## 🎯 Como Usar

### Opção 1: Importar em Obsidian (Recomendado)

#### Passo 1: Criar Pasta
1. Abra seu vault Obsidian
2. Crie uma pasta: **`RH/Descritivos-Funcoes`**
3. (Ou use o nome que preferir)

#### Passo 2: Copiar Arquivos
**Método A - Copia Manual:**
- Copie os 9 arquivos `.md` para a pasta
- Pronto! Obsidian detecta automaticamente

**Método B - Copia em Lote (mais rápido):**
```bash
# No seu terminal/prompt:
# Windows:
copy *.md "C:\Users\[seu-user]\Obsidian Vault\RH\Descritivos-Funcoes\"

# Mac/Linux:
cp *.md ~/Obsidian\ Vault/RH/Descritivos-Funcoes/
```

#### Passo 3: Ativar Wikilinks
1. Em Obsidian → **Settings** → **Files & Links**
2. Ative `Use [[Wikilink]]` (deve estar ativado por padrão)
3. Feche settings

#### Passo 4: Testar
1. Abra `INDICE-FUNCOES-LIDERANCA.md`
2. Clique em qualquer link azul tipo `[[gerente-negocios]]`
3. Deve abrir o arquivo correspondente ✅

### Opção 2: Usar em Outro Aplicativo (Google Docs, Notion, etc.)

Os arquivos são **100% compatíveis** com qualquer app que leia Markdown:

- Dataview blocks (específico Obsidian)
- Wikilinks podem não funcionar

## 📖 Estrutura de Cada Arquivo

Cada descritivo segue este padrão (para fácil scanning):

```
1. HEADER (YAML frontmatter)
   └─ Tipo, Área, Nível, Status, Tags

2. IDENTIFICAÇÃO
   └─ Cargo, Reporta a, Supervisiona

3. MISSÃO & PROPÓSITO
   └─ Resumo executivo (2-3 linhas)

4. RESPONSABILIDADES (com checkboxes ☑️)
   └─ Agrupadas por categoria

5. KPIs CRÍTICOS
   └─ Tabela com metas e frequência

6. COMPETÊNCIAS & REQUISITOS
   └─ Formação, Experiência, Técnicas, Comportamentais

7. EXEMPLO DE DIA TÍPICO
   └─ Cronograma 08:00-17:00

8. INTERFACES & RELACIONAMENTOS
   └─ Internas e Externas

9. DOCUMENTOS CRÍTICOS
   └─ Domínios obrigatórios

10. DESENVOLVIMENTO & CARREIRA
    └─ Próximas posições + Treinamentos

11. DESAFIOS TÍPICOS
    └─ Tabela com estratégias

12. MÉTRICAS DE SUCESSO
    └─ 3 meses | 6 meses | 12 meses

13. PROCESSOS CRÍTICOS
    └─ Fluxos principais

14. CHECKLIST DE ONBOARDING
    └─ Primeiros 60-90 dias

15. IDEIAS DE INICIATIVAS
    └─ Melhorias sugeridas

16. DATAVIEW & LINKS
    └─ Análises dinâmicas + Wikilinks
```

## 🔍 Como Navegar

### Buscar Função por Responsabilidade
1. Abra `INDICE-FUNCOES-LIDERANCA.md`
2. Use **Ctrl+F** (Cmd+F no Mac) para buscar palavra-chave
3. Ex.: "renovação" → encontra `coordenador-negocios.md`

### Seguir Carreira
```
Coordenador → Gerente → Diretor

Exemplo:
coordenador-negocios → gerente-negocios → diretor-superintendente
```

### Comparar Funções
1. Abra 2 abas lado-a-lado em Obsidian
2. Ex.: `gerente-marketing.md` vs `coordenador-marketing.md`
3. Veja diferenças em KPIs, responsabilidades, experiência
