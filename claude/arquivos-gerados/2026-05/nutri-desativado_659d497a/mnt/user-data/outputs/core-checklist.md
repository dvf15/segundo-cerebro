# 🦵 Core — Checklist

**Big 3:** pirâmide **6 → 4 → 2** · hold **~10 s** cada · descanso 20–30 s

## Big 3
- [ ] **Curl-up** — 6/4/2 _(mãos sob a lombar, sobe 2–3 cm, troca a perna)_
- [ ] **Prancha lateral D** — 6/4/2 _(cotovelo sob o ombro, linha reta)_
- [ ] **Prancha lateral E** — 6/4/2
- [ ] **Bird-dog D** — 6/4/2 _(braço+perna opostos, coluna neutra)_
- [ ] **Bird-dog E** — 6/4/2

## Pescoço — 3 × 30 s _(mão empurra, pescoço resiste, cabeça parada)_
- [ ] Frente
- [ ] Trás
- [ ] Lateral D
- [ ] Lateral E
