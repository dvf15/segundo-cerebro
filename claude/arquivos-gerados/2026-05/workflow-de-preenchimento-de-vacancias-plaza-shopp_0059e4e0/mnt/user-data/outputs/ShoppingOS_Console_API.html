Zona de risco

Configurar API Anthropic

Cole sua chave de API. Ela fica salva no seu navegador (não é enviada a nenhum servidor além do api.anthropic.com).

Segurança: chave fica no localStorage do navegador. Não use este sistema em máquinas compartilhadas. Em produção/escala, use proxy backend.
Crie em console.anthropic.com/settings/keys
Web search adiciona ~$0.01 por tool call. Workflows com filtro de duplicidade precisam.
Limite de tokens da resposta. Workflows complexos podem precisar 8000+.
