# Glossário

## Estágios do Pipeline (Deal Conversion Layer)

| Estágio | Definição |
|---|---|
| Lead | Marca identificada como candidata. Nenhum contato ainda. |
| Qualified Lead | Lead que passou pelo filtro de duplicidade e cluster fit. |
| Contacted | Primeiro contato comercial realizado (email/LinkedIn/visita). |
| Meeting Scheduled | Reunião agendada com a marca-alvo. |
| Meeting Done | Reunião realizada. Próximos passos definidos. |
| Proposal | Proposta comercial enviada. |
| Technical Feasibility | Análise técnica do espaço pela marca (m², infra, vitrine). |
| Investor Match | Match com investidor identificado pelo Farmer. |
| Contract Negotiation | Negociação contratual em curso. |
| Contract Signed | Contrato assinado — meta principal do Workflow 1. |
| Construction / Obra | Obra em andamento — acompanhar via Builder. |
| Opening | Loja inaugurada. |
| Ramp-up | Loja em ramp-up (primeiros 6 meses). |
| Performance Review | Revisão pós-ramp-up. |
| Lost / Parked | Oportunidade perdida ou pausada (manter para histórico). |

## Status no Plaza (filtro de duplicidade)

| Status | O que fazer |
|---|---|
| AUSENTE | Marca confirmada não-presente. Elegível para pipeline. |
| n.v. - verificar duplicidade | Não verificado. Investigar antes de avançar. |
| JÁ EXISTE - descartar | Marca já no shopping. Descartar do pipeline. |

## Scores

### Cluster Fit (0–100)
- **0–40:** baixo. Não priorizar, salvo emergência de vacância.
- **41–70:** aceitável. Priorizar apenas se houver pressão de ocupação ou ganho financeiro claro.
- **71–85:** forte. Priorizar.
- **86–100:** estratégico. Priorizar mesmo com negociação difícil. Sponsor executivo obrigatório.

### Probabilidade (%)
Probabilidade subjetiva de fechamento. Base para Pipeline Ponderado (ABL × Prob).

## Workflows do Framework Shopping Inteligente OS v5

1. **Workflow 1 — Vacancy-to-Contract Sprint:** reduzir vacância monetizada e tempo de reposição. **Este sistema cobre este workflow.**
2. **Workflow 2 — Street-to-Shopping Conversion Sprint:** converter varejo qualificado de rua.
3. **Workflow 3 — Cluster Experience Growth Sprint:** aumentar frequência, ticket, experiência.
