📊 Guia Completo: Planilha Bazin + Puts

✅ O que você vai conseguir:
  • Atualização automática de preços (1x por hora)
  • Cálculo automático do Preço Justo (método Bazin)
  • Formatação condicional (cores indicando barato/caro)
  • Seção de puts com análise de retorno

🚀 Passo 1: Criar a Planilha Base

1.1 - Acesse Google Sheets

  • Vá para sheets.google.com
  • Crie uma nova planilha em branco
  • Nomeie como: "Análise Bazin - Ações + Puts"

1.2 - Estruture as Abas

Crie 2 abas (clique no + no canto inferior esquerdo):

  • Aba 1: "Ações" → para análise Bazin
  • Aba 2: "Puts" → para opções de venda

📋 Passo 2: Montar a Aba "Ações"

2.1 - Cabeçalho (Linha 1)

Copie e cole na linha 1:

ABCDEFGHI
TICKERPREÇO ATUALDPACRESC. %P/LDIV. YIELD %PREÇO JUSTOMARGEM SEG. %STATUS

2.2 - Dados das Ações (Linhas 3-7)

LinhaColuna A (TICKER)O que preencher
3AAPL3Manual + Automático
4KLBN4Manual + Automático
5ITSA4Manual + Automático
6BBDC4Manual + Automático
7AXIA3Manual + Automático

2.3 - Coluna B: Preço Atual (Automático)

Deixe em branco! O Apps Script vai preencher automaticamente.

Ou use a fórmula manual (se preferir):

=GOOGLEFINANCE("AAPL3.SA","price")

2.4 - Colunas C, D, E, F: Dados Fundamentais (Manual)

Para cada ação, você precisa buscar:

ColunaSignificadoOnde buscarFrequência
C - DPADividendo Por AçãoFundamentus ou site da empresaAnual
D - Cresc %Crescimento do DPA (%)Média dos últimos 5 anosAnual
E - P/LPreço / LucroFundamentusDiário
F - Div. Yield %Dividendo / PreçoFundamentus ou (DPA/Preço)×100Diário
💡 Dica: Para DIV. YIELD, você pode usar a fórmula:
=C3/B3*100
(Que quer dizer: DPA ÷ Preço Atual × 100)

2.5 - Coluna G: Preço Justo (Fórmula Bazin)

Copie esta fórmula na célula G3 e repita para G4:G7:

=((C3*(1+D3/100)^5)*(E3+(F3/100)))/0.11

O que significa:

  • C3*(1+D3/100)^5 → DPA projetado em 5 anos
  • E3+(F3/100) → P/L alvo + Dividend Yield
  • /0.11 → Taxa de desconto (11% = SELIC)
⚠️ Importante: Altere 0.11 para outra taxa se quiser (ex: 0.09 para 9%)

2.6 - Coluna H: Margem de Segurança

Copie na célula H3:

=(G3-B3)/G3*100

Repita para H4:H7

Interpretação:

  • ≥ 20%: Muito barata (compre!)
  • 10-19%: Barata (considere)
  • 0-9%: Neutra (espere)
  • < 0%: Cara (evite)

2.7 - Coluna I: Status (Fórmula IF)

Copie na célula I3:

=IF(H3>=0.20,"✅ MUITO BARATA",IF(H3>=0.10,"🟢 BARATA",IF(H3>=0,"🟡 NEUTRA","❌ CARA")))

Repita para I4:I7

🎨 Passo 3: Formatação Condicional

3.1 - Colorir Status (Coluna I)

  1. Selecione I3:I7
  2. Vá em Formato → Formatação condicional
  3. Crie 4 regras:
    • Se =REGEXMATCH(I3,"MUITO BARATA") → Fundo verde
    • Se =REGEXMATCH(I3,"BARATA") → Fundo amarelo claro
    • Se =REGEXMATCH(I3,"NEUTRA") → Fundo cinza
    • Se =REGEXMATCH(I3,"CARA") → Fundo vermelho

3.2 - Colorir Margem de Segurança (Coluna H)

  1. Selecione H3:H7
  2. Formato → Formatação condicional
  3. Escala de cores: Verde (>20%) → Amarelo (10%) → Vermelho (<0%)

💾 Passo 4: Adicionar Apps Script (Automação)

4.1 - Abrir Editor de Scripts

  1. Na sua planilha, vá em Extensões → Apps Script
  2. Será aberta uma nova aba

4.2 - Copiar e Colar o Script

  1. Apague todo o código que está lá (função vazia)
  2. Cole o código que foi enviado (bazin_script.gs)
  3. Clique em Salvar (Ctrl+S)

4.3 - Autorizar o Script

  1. Clique em Executar
  2. Vai pedir permissão → clique em Autorizar
  3. Selecione sua conta Google
  4. Conceda as permissões

4.4 - Criar Triggers (Automação Horária)

  1. Volta para o Apps Script
  2. À esquerda, clique em Acionadores (relógio)
  3. Clique em + Criar acionador
  4. Configure:
    • Executar: atualizarPrecos
    • Tipo de evento: No prazo
    • Intervalo de tempo: A cada 1 hora
    • Hora do dia: Qualquer hora
  5. Clique em Salvar
✅ Pronto! Agora a cada 1 hora, os preços vão ser atualizados automaticamente!

📊 Passo 5: Montar a Aba "Puts"

5.1 - Cabeçalho (Linha 1)

ABCDEFGHI
AÇÃOCONTRATOSTRIKEPRÊMIOPREÇO AÇÃORETORNO %DIAS VENCRET. ANUAL %STATUS

5.2 - Preenchimento Manual (Linhas 3+)

Você alimenta com os contratos de puts disponíveis no seu broker. Exemplo:

ABCDE
AAPL3AAPL3D1001005120
KLBN4KLBN4D4545250

5.3 - Coluna F: Retorno % do Put

Copie na célula F3:

=D3/C3*100

Significado: Quanto % você ganha se a ação for exercida

5.4 - Coluna G: Dias até Vencimento

Você atualiza manualmente conforme o tempo passa:

=HOJE()-DATA_VENCIMENTO

Ou simplesmente coloque manualmente e atualize quando precisar

5.5 - Coluna H: Retorno Anualizado

Copie na célula H3:

=F3*(365/G3)

O que significa: Se a put vencer em 30 dias com 4% de retorno, anualizado fica ~48%

5.6 - Coluna I: Status Propício

=IF(AND(H3>=30,F3>=3),"✅ LANÇAR PUT",IF(H3>=20,"🟡 CONSIDERAR","❌ AGUARDE"))

Critério: Lança put se:

  • Retorno anualizado ≥ 30% E
  • Retorno do contrato ≥ 3%

(Você pode ajustar esses valores conforme sua estratégia)

5.7 - Formatação Condicional (Puts)

  1. Selecione coluna I (Status)
  2. Formato → Formatação condicional
  3. Crie 3 regras:
    • ✅ LANÇAR → Verde
    • 🟡 CONSIDERAR → Amarelo
    • ❌ AGUARDE → Vermelho

🔄 Passo 6: Atualizar Automaticamente Quando Put Vencer

⚠️ Para puts, é semi-automático:
  • Você muda o contrato quando vence (B3, B4, etc)
  • Você muda o strike e prêmio (C3, D3, etc)
  • Você atualiza os dias até vencimento (G3, G4, etc)
  • Tudo o mais recalcula automaticamente!

6.1 - Exemplo: Quando Put Vence

Sua put AAPL3D100 vence em 30 dias:

Hoje: Contrato AAPL3D100 | Prêmio 5 | Dias: 30
Em 30 dias: Mude para AAPL3E95 | Prêmio 4.5 | Dias: 30 (novo vencimento)

Tudo o mais atualiza sozinho! ✨

📱 Dicas Finais

💡 Boas práticas:
  • Atualizar DPA/Crescimento: 1x ao mês (ou anual)
  • Atualizar Puts: Quando o contrato vencer ou a cada semana
  • Revisar Preço Justo: Mensal (conforme dados fundamentais)
  • Preços: Atualizam sozinhos a cada 1 hora ✅
⚠️ Atenção:
  • O GOOGLEFINANCE pode ter pequeno delay (5-15 min)
  • Se der erro no Apps Script, verifique se os nomes das abas estão corretos
  • Este é um sistema indicativo - sempre confirme antes de operar!
